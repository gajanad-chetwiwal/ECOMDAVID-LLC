# ECOMDAVID LLC — Website

Static website for Ecom David: Google Merchant Center and Google Ads services for eCommerce stores.

Plain HTML/CSS/JS with no build step.

- `index.html`, `services.html`, `about.html`, `contact.html`, `privacy.html`, `terms.html`, `refund-policy.html`, `404.html`
- `styles.css`: all styling
- `script.js`: mobile menu and contact form
- `vercel.json`: clean URLs (`/contact` instead of `/contact.html`)

## Deploy on Vercel
Import this repo in Vercel and set **Framework Preset: Other** with no build command and no output directory. That's it.

## Contact form
The form posts to [FormSubmit](https://formsubmit.co) and delivers to `support@ecom-david.com`.
The first submission triggers a one-time activation email to that inbox. Click the link in it to start receiving form messages.
